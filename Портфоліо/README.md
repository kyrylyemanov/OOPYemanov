# 💻 Кирил | IT Portfolio

Мінімалістичне портфоліо з прикладами моїх навчальних та практичних проєктів у сферах Backend, Баз даних та Web-розробки.

---

## 🛠️ Технологічний стек

* **Backend:** Python 3.13+ (ООП, Poetry, розробка AI-агентів через Google ADK та Gemini API)
* **Data:** SQL / MySQL (проєктування реляційних баз даних, написання аналітичних запитів)
* **Frontend:** HTML5, CSS3, UI/UX прототипування у Figma

---

## 📁 Виконані роботи

### 🤖 1. AI Агенти (Google ADK)
* **Safe Math Agent:** Математичний асистент із превентивною перевіркою та валідацією вхідних даних.
* **Stateful Agent:** Реалізація персистентної пам'яті ШІ із збереженням стану розмови у JSON-файли.
* **Workflows:** Побудова та тестування послідовних (Sequential), циклічних (Loop) та паралельних бізнес-процесів для моделей Gemini.

### 📊 2. Реляційна БД "Університет"
* Створення структури таблиць для обліку кафедр, викладачів та студентів.
* Написання та оптимізація SQL-запитів для генерації звітів та аналітики.

### 🌌 3. Веб-сайт про Космос (Курсова робота)
* Створення адаптивних макетів інтерфейсу у Figma (для екранів 1440px та 375px).
* Чиста верстка трьох сторінок сайту з послідовною навігацією за допомогою HTML та CSS.
