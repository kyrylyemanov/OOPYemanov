📋 ШАГИ ДЛЯ ЗАПУСКУ:

1. АКТИВУЙТЕ ВІРТУАЛЬНЕ СЕРЕДОВИЩЕ:

   source venv/bin/activate

2. ЗАПУСТІТЬ ДЕМОНСТРАЦІЮ OOP (БЕЗ ПОТРЕБИ API):
   python demo_oop.py
   
   Це покаже роботу всіх 4 парадигм ООП:
   ✅ Абстракція
   ✅ Наслідування
   ✅ Інкапсуляція
   ✅ Поліморфізм

3. ЗАПУСТІТЬ AI АГЕНТ (ПОТРЕБУЄ GOOGLE API KEY):
   python agent.py
   
   Перед запуском:
   - Отримайте Google API ключ на https://ai.google.dev/
   - Вставте його в файл .env
   - Замініть значення GOOGLE_API_KEY

📚 ФАЙЛ AGENT.PY МІСТИТЬ:

1. OOP КЛАСИ (ВСІ 4 ПАРАДИГМИ):
   ✅ LibraryItem (ABC) - АБСТРАКЦІЯ
   ✅ Book(LibraryItem) - НАСЛІДУВАННЯ
   ✅ Magazine(LibraryItem) - НАСЛІДУВАННЯ
   ✅ Library - ІНКАПСУЛЯЦІЯ з __catalog
   ✅ get_info() - ПОЛІМОРФІЗМ

2. AI ІНСТРУМЕНТИ (TOOLS):
   • search_catalog_tool() - Пошук видання
   • list_catalog_tool() - Список видань (з фільтрацією)
   • get_catalog_stats_tool() - Статистика

3. AI АГЕНТ:
   • create_root_agent() - Налаштування агента
   • run_agent_conversation() - Взаємодія з AI
   • main() - Демонстрація

🔧 НАЛАШТУВАННЯ GOOGLE API:

1. Перейдіть на: https://ai.google.dev/
2. Натисніть "Get API Key" або "Get Started"
3. Виберіть/створіть проект
4. Скопіюйте API ключ
5. Вставте в файл .env:
   GOOGLE_API_KEY=YOUR_KEY_HERE

⚠️ ПОШИРЕНІ ПРОБЛЕМИ:

→ Перевірте .env файл, вставте правильний ключ

→ Запустіть: pip install google-genai python-dotenv

→ Файл збережіть як UTF-8
